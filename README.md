## Editing the portfolio

Edit [content.md](content.md). It contains every portfolio card and all About-page text in one place, with an example card format at the top. Card colours and filter counts update automatically from the card category (`course`, `project`, `film`, or `hobby`).

Add an image path or URL after a card's `image:` field to show it on the card (cropped square) and at the top of that card's reading page. Leave `image:` blank for a typographic card
